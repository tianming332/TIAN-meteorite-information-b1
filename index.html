信息可视化 · 数据可视化 · 信息设计 · 实验设计 / 2021–2024

陨石的漫长旅程

THE LONG JOURNEY OF A METEORITE

从天体数据到陨石实体的信息可视化系统。

00 / PROJECT OVERVIEW

一块落在地面上的陨石，连接着来源、运动、时间、地理与内部物质结构。

项目从陨石的来源、轨迹、坠落记录与物质构成出发，将空间、时间、类别、物理属性与成分等不同尺度的数据拆解并编码为统一的视觉语言。轨迹图、坠落分布图与成分图建立连续的数据阅读系统，二维图表中的颜色、晶体结构与几何关系最终又被转译为三维晶体对象。

DESIGN QUESTION

00

一块陨石能够包含多少信息？

肉眼看到的陨石可能只是一块具有特殊颜色、纹理与形态的石头；当它被放回天文学尺度中，它同时连接来源、位置、运动、时间、地理、物理性质与内部物质结构。核心问题因此不是怎样画一张关于陨石的信息图，而是怎样让不同尺度、不同类型的数据使用同一套视觉语言被阅读。

01 / INFORMATION MAP

01

建立信息坐标

从一块陨石回到它的旅程

项目首先把陨石从孤立物体还原为连续事件，再把旅程中的信息拆分为空间、时间、类别、物理与物质五类，并建立从宇宙到地球、再进入物质内部的阅读顺序。

01.1 从物体到事件01.2 拆分信息类型01.3 跨尺度阅读

01.1｜从物体到事件

天体脱离原有环境并运动，进入大气层形成可观察现象，最终抵达地表并留下陨石。由此建立“天体 → 运动 → 坠落 → 地表记录 → 陨石”的基础路径。

01.2｜拆分不同类型的信息

位置、距离与轨迹回答如何运动；年份与事件回答何时发生；类别回答它是什么；质量与直径描述物理差异；矿物与晶体结构回答由什么构成。

01.3｜建立跨尺度阅读顺序

项目没有把所有数据压进一张图，而是按照观察尺度逐层展开：宇宙尺度理解来源与运动，地球尺度理解坠落与记录，物质尺度理解成分与晶体。

02 / VISUAL ENCODING

02

建立视觉编码

让不同数据共享一套语言

颜色、几何轮廓、尺度、坐标、环形结构与连接关系被转化为视觉变量。形状区分类别，颜色建立跨图表识别，位置与环形坐标表现空间和周期，尺度与数量辅助表达物理差异。

02.1 形状承担类别02.2 颜色建立对应02.3 坐标与尺度02.4 图表规则

02.1｜形状承担类别

天体、陨石类别与晶体结构被抽象为具有差异的几何轮廓。形状不是装饰性标志，而是在轨迹图、成分图与分类图中反复出现的数据识别单位。

02.2｜颜色建立对应

相同颜色在不同图表中保持矿物、晶体与类别之间的关联，使读者无需重复阅读大量文字，也能通过视觉线索追踪信息。

02.3｜坐标、尺度与连接关系

环形坐标组织空间、周期与分类关系；点、线、面积和位置表现分布、轨迹与对应；尺度与数量辅助呈现物理差异。

02.4｜从视觉字典到图表规则

完成基础编码后，项目让同一套规则进入不同数据问题，使后续图表成为同一系统的不同视图，而不是彼此独立的视觉作品。

03 / COSMIC SCALE

03

宇宙尺度

把位置与运动变成可阅读的轨迹

环形坐标、轨迹线、类别符号与颜色把难以直接感知的宇宙距离与周期关系压缩到同一平面。环形结构既形成视觉中心，也承担空间、周期与比较功能。

03.1 位置与轨迹03.2 坐标、标尺与图例

03.1｜完整轨迹图

图表并不模拟真实宇宙，而是在有限平面中保留数据关系，使读者能够同时观察单一天体特征与不同天体之间的关系。

03.2｜轨迹、类别、标尺与图例

完整图之后以说明页和实体印刷细节补充坐标、颜色与类别如何共同工作，避免只展示缩小后的复杂图表。

04 / EARTH SCALE

04

地球尺度

把坠落转化为时间与地理记录

观察尺度从宇宙收缩到地球，信息类型转向具体事件：坠落年份、地理位置、质量、直径、陨石类别与陨石坑被组织在同一图表中。

04.1 坠落记录04.2 地理与物理属性

04.1｜世界坠落分布

单次坠落不再只是地图上的地点，而是同时具有时间、空间、类别和物理属性的数据记录。

04.2｜同一编码迁移到地理数据

这一阶段延续前一部分的颜色和符号体系，同时改变坐标结构以适应地理数据，验证视觉语言在不同信息尺度中的可迁移性。

05 / MATERIAL SCALE

05

物质尺度

进入一块陨石的内部

观察继续缩小，项目从它如何抵达转向它由什么构成。矿物组成、元素、晶体结构与颜色成为新的数据层，并通过几何轮廓、比例和颜色建立对应。

05.1 成分与晶体05.2 类型比较

05.1｜成分总图与晶体类别

此前用于描述宇宙运动和坠落事件的视觉语言进入物质内部，实现从宏观空间到微观结构的连续阅读。

05.2｜同一系统下的类型比较

不同陨石类型的图表是同一编码系统下的比较视图：数据改变，图形结果随之变化；形状、颜色、坐标与图例规则保持稳定。

06 / DATA PHYSICALIZATION

06

数据实体化

从分析重新生成一个物体

前半段路径是“真实陨石 → 数据 → 视觉编码 → 信息图表”；最终阶段反向操作，从二维图表中提取颜色、晶体结构与几何关系，将它们重新生成三维信息实体。

06.1 反向转译06.2 十二组晶体06.3 信息实体06.4 从阅读到感知

06.1｜反向转译

彩色晶体并非对真实矿物的精确复制，而是数据经过视觉规则后形成的信息实体。颜色延续分类关系，折面与几何结构来自晶体形态的抽象。

06.2｜十二组数据晶体

十二个晶体对象分别保留独立的颜色、透明度与折面关系。连续陈列既呈现单体差异，也让读者看见同一编码系统如何生成一个完整系列。

06.3｜可以被拿起、佩戴与排列的信息实体

图表中的信息离开平面，进入手部、首饰与透明媒介；阅读由视觉比较扩展为尺度、材质、光线与身体共同参与的体验。

06.4｜从阅读到展览空间

实体晶体与数据图表共同进入展示环境，项目完成“真实物体 → 数据 → 图形 → 图表 → 新物体”的闭环。

07 / CONCLUSION

07

从真实世界提取数据，再通过数据重新生成一个可以被感知的物体。

项目建立的不是一张百科式陨石图表，而是一套跨越不同信息尺度的视觉组织方法。空间、时间、类别、物理性质与物质结构被拆分为数据层，再通过形状、颜色、坐标、尺度和连接关系建立统一编码。视觉语言从宇宙进入地球与物质内部，最终又从二维图表转译为三维晶体，完成从分析到生成的闭环。

核心设计路径

  1. 01研究与拆分信息
  2. 02建立视觉变量
  3. 03组织宇宙数据
  4. 04组织地球记录
  5. 05进入物质结构
  6. 06重新实体化
